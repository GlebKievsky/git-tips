# Как предложить совет

Спасибо, что хочешь помочь проекту! Изменения принимаются только через fork и Pull Request.

## Шаги

1. Выбери задачу с меткой **good first issue** во вкладке Issues. Напиши в ней комментарий «Беру», чтобы другие видели, что задача занята.
2. Сделай fork репозитория и склонируй **свой** fork.
3. Создай ветку `tip/<тема>`, например `tip/git-stash`.
4. Скопируй файл `tips/_template.md` в новый файл `tips/<тема>.md` и заполни все разделы.
5. Добавь строку со ссылкой на свой совет в конец таблицы в `README.md`.
6. Сделай коммит и отправь ветку в свой fork.
7. Открой Pull Request в этот репозиторий:
   - заголовок — `Совет: <тема>`;
   - описание — по шаблону, со строкой `Closes #<номер задачи>`.
8. Если ревьюер попросит правки — внеси их в той же ветке и отправь: Pull Request обновится сам.

## Правила

- Один совет — один Pull Request.
- Пиши простыми словами и обращайся к читателю на «ты».
- Пример — настоящий: команда и вывод, который она дала у тебя.
