# История веток в виде графа

**Команда:** `git log --oneline --graph --all`

## Когда пригодится

Нужно увидеть, где ветки разошлись и где снова слились. `--oneline` — один коммит в строке, `--graph` — линии веток слева, `--all` — все ветки, а не только текущая.

## Пример

```bash
$ git log --oneline --graph --all
*   4924892 Merge branch 'feature/timer'
|\
| * e0bc12e Show quiz time
* | 61854e2 Add team rules
|/
* 84de0e2 Create project
```

## Что важно знать

Звёздочка — это коммит, линии слева — ветки. Здесь после «Create project» история разошлась на две ветки, а коммит слияния сверху соединил их снова.
