# Вернуться на предыдущую ветку

**Команда:** `git switch -`

## Когда пригодится

Ты переключаешься между двумя ветками туда и обратно: например, правишь `feature/timer` и заглядываешь в `main`. Минус вместо имени ветки означает «ветка, на которой я был до этого».

## Пример

```bash
$ git switch main
Switched to branch 'main'
Your branch is up to date with 'origin/main'.

$ git switch -
Switched to branch 'feature/timer'
```

## Что важно знать

Команда помнит только одну предыдущую ветку. Если переключиться три раза подряд, `git switch -` вернёт на ветку перед последним переключением.
